# The Coma Cluster Distance Audit — Version 2

**Research question:** How does the choice of redshift-independent distance indicator affect a cluster-scale estimate of the Hubble constant for the Coma Cluster?

This repository contains a reproducible statistical analysis of ten listed Coma Cluster distance records. Using the fiducial velocity of 7194 km/s, each distance is converted to an implied H0 = v/D.

## Main result
The median listed distance is 104.0 Mpc, corresponding to an implied cluster-scale H0 of about 69.2 km/s/Mpc. The implied values span about 50.0–93.6 km/s/Mpc.

This is a descriptive audit, not a precision measurement of H0. The records are heterogeneous and are not all independent.
